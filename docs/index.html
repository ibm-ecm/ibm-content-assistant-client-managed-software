IBM Content Assistant

Generative AI for Enterprise Content on Kubernetes & OpenShift

Unlock natural language insights across your IBM Content Cortex repository. Summarize documents, compare versions, and answer questions using watsonx LLMs — deployed as a client-managed add-on to your existing CPE + Content Navigator environment on IBM Content Cortex or IBM Cloud Pak for Business Automation (CP4BA). A single Helm chart installs the operator, which deploys and manages the GenAI Connector. Usage is metered automatically via IBM Usage Metering Service (UMS).

v1.0.x Kubernetes 1.24+ OpenShift 4.12+ Helm 4.0+ watsonx LLM

Key Features

🤖

Natural Language Queries

Ask questions in plain English across your entire Content Cortex repository and receive accurate, context-grounded answers powered by IBM watsonx LLMs.

☸️

Client-Managed Deployment

Deploy Content Assistant as an add-on to your existing Content Cortex or CP4BA environment on Kubernetes or OpenShift — your content never leaves your infrastructure.

🔒

Enterprise Security

Adheres to Content Cortex's enterprise-grade security model and access controls. Full traceability with document inspection and Q&A auditability.

📝

Document Summarization

Automatically generate tailored summaries of lengthy documents — including contracts, policies, and reports — reducing manual review time dramatically.

🔍

Document Comparison

Compare documents and versions side-by-side to surface differences — such as changes between two versions of a policy or contract.

🧠

RAG-Powered Accuracy

Retrieval-Augmented Generation (RAG) grounds every answer in your specific repository content, preventing hallucinations and ensuring responses are relevant to your business.

Quick Start

1

Setup Environment

git clone https://github.com/ibm-ecm/ibm-content-assistant-containers.git
cd ibm-content-assistant-containers/scripts

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
2

Deploy Operators

Interactive deployment of the Content Assistant operator with guided configuration.

python deploy_operator.py
3

Configure & Deploy

Gather deployment properties, generate deployment artifacts, and validate your Content Assistant configuration.

# Gather deployment properties
python prerequisites.py gather

# Generate deployment artifacts
python prerequisites.py generate

# Validate all properties
python prerequisites.py validate

Architecture Overview

IBM Content Assistant is a single-chart add-on. Install the operator — it provisions and manages the GenAI Connector for you. Content Assistant runs alongside your existing Content Cortex or CP4BA deployment, and usage is metered automatically via UMS.

IBM Content Assistant Operator

v1.0.4 — Install this

The single Helm chart you install. This namespace-scoped Kubernetes operator manages the complete lifecycle of IBM Content Assistant — it deploys, configures, and upgrades the GenAI Connector Service automatically via a ContentAssistant Custom Resource.

  • ✓ One chart installs everything
  • ✓ Deploys & manages the GenAI Connector
  • ✓ Custom Resource (CR) driven configuration
  • ✓ Air-gap / offline deployment support
View Chart →

GenAI Connector Service

Deployed by operator

The AI service managed and deployed by the operator — not installed separately. Bridges IBM Content Cortex with IBM watsonx LLMs using Retrieval-Augmented Generation (RAG) to deliver natural language Q&A, summarization, and document comparison.

  • ✓ Natural language Q&A across CPE repositories
  • ✓ Document summarization & comparison
  • ✓ RAG-powered watsonx LLM integration
  • ✓ Lifecycle fully managed by the operator
Documentation →

CPE + Content Navigator (Foundation)

Prerequisite

Content Assistant is an add-on to an existing IBM Content Cortex or CP4BA deployment. Content Platform Engine (CPE) and Content Navigator must already be running on IBM Content Cortex or IBM Cloud Pak for Business Automation (CP4BA).

  • ✓ IBM CP4BA or IBM Content Cortex deployment
  • ✓ Content Platform Engine (CPE)
  • ✓ Content Navigator (ICN)
  • ✓ CPE object store & enterprise security model
Learn More →

IBM Usage Metering Service (UMS)

Usage Metering

Content Assistant reports usage automatically to IBM through the IBM Usage Metering Service (UMS). No manual license tracking is required — metering is built into the operator and activated via your IBM entitlement key.

  • ✓ Automatic usage reporting to IBM
  • ✓ Activated via IBM entitlement key
  • ✓ No separate metering configuration required
  • ✓ Consistent with CP4BA & Content Cortex licensing
Documentation →

LLM Endpoint

Bring Your Own

Content Assistant supports flexible AI hosting. Connect directly to IBM watsonx.ai or route requests through IBM AI Model Gateway to access a broad range of models — on IBM Cloud, AWS, or on-premises.

  • ✓ IBM watsonx.ai SaaS (IBM Cloud)
  • ✓ IBM watsonx.ai SaaS (AWS)
  • ✓ Self-managed watsonx on-premises
  • IBM AI Model Gateway (proxy to multiple LLM providers)
  • ✓ OpenSearch vector database integration
