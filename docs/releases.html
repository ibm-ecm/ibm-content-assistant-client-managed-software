🔄 Upgrade Paths

Supported upgrade paths for IBM Content Assistant 1.0.x

any 1.0.x → 1.0.4 ✓ Supported

ℹ️ Prerequisite: IBM Content Cortex or CP4BA (CPE + ICN) must already be deployed and operational before upgrading IBM Content Assistant. See the IBM Content Assistant documentation for full upgrade instructions.

🛠️ Upgrade via Helm

Use Helm to upgrade the operator (which manages the GenAI Connector automatically):

helm repo update

# Upgrade operator (automatically upgrades the GenAI Connector)
helm upgrade content-assistant-operator ibm-content-assistant/ibm-content-assistant-operator \
  --namespace ibm-content-assistant
